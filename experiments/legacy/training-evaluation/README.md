# External training qualification programs

Supplement S12 cites a finite qualification study, not a completed training accuracy or framework-throughput comparison. This collection restores its first-party adapters, drivers, protocols, small fixtures and source identities from the migration archive at the approved cutoff. Later live development is not substituted for this capture.

`adapters/` implements framework-specific qualification calls; `tools/` contains qualification and campaign programs. `protocol/` and `fixtures/` contain the recorded contracts and bounded inputs. `sources/` preserves source identities. The byte-identical engine snapshot and revision overlays are sealed in `frozen-sources.tar.gz` under their original `snapshot/` and `revisions/` paths. Inspect or unpack it into a separate directory before preparing a historical environment. They are evidence sources, not the maintained Atlas implementation.

Framework packages, datasets, model binaries, full scientific outputs and original host environments are separate dependencies. Original paths and launch assumptions are retained; running a driver is not part of this migration check. The paper's evidence scope remains in [external_training_qualification.md](../../../paper/data/v3/external_training_qualification.md).

All imported members are listed and hashed in [the import manifest](../../../migration/paper-experiment-code-import-20261009.json). This import does not change performance_run=false or complete_evaluation=false for the cited study.
