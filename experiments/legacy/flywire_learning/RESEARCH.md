## 1. 初期依据与规则选择

[Bennett et al., 2021](https://www.nature.com/articles/s41467-021-22592-4)
给出了蘑菇体奖励预测误差学习模型，讨论 MBON 输出反馈和 DAN 教学信号。
这里借鉴“预测与实际奖励的差异驱动局部权重更新”的研究路线。
其对 DAN 的解释包含模型假说，不作为所有果蝇 DAN 都编码预测误差的实验证明。
[作者代码](https://github.com/BrainsOnBoard/paper_RPEs_in_drosophila_mb)
可用于下一阶段核对，当前没有复制代码或声称复现论文。

[Huang et al., 2024](https://www.nature.com/articles/s41586-024-07819-w)
结合生理实验和连接组约束模型，研究分区 KC→MBON 塑性及 MBON→DAN 反馈
与不同时间尺度的记忆相互作用。这支持从有定义的学习分区开始。
该研究的拟合参数和长时记忆机制尚未移植；当前参考模型不能检验巩固。

[FlyWire 数据](https://zenodo.org/records/10676866) 与
[v783 连接组论文](https://www.nature.com/articles/s41586-024-07558-y)
提供结构约束，数据采用 CC BY 4.0。学习规则、奖励映射和可变权重不是
从解剖接触计数直接测得的生理量。沿用仓库原有数据归属和引用。

一期选择：先做有界局部学习，维持拓扑与 KC 输出连接的兴奋符号。
纯时序 STDP 不定义任务目标；奖励门控、奖励预测误差和替代梯度训练
是不同方案。本次仅提供抽象的预测误差参考，不称为全脑 STDP 或强化学习智能体。

需要解决的数据问题：

- 当前 EI 导入以 `signed_contacts = contacts * fast_sign` 保存权重。
  大多数 DAN 的 fast_sign 为零，因此有边但此文件不再保留这些边的接触数量。

## 3. 合成机制参考及首轮结果

该参考是自行定义的速率模型，用于验证实验方向和数值实现，不使用 FlyWire 边。
两个刺激各激活 16/128 KC，其中 4 个共享；响应有 10% dropout 和少量背景噪声。
KC 响应 x 归一化为和 1，两个抽象 MBON 通道权重初始同为 0.75，界限 [0,1.5]。

```text
v = x · (w_plus - w_minus)
delta = reward - v
e = x * exp(-reward_delay / tau)
d = eta * learning_gate * delta * e / (2 * x·x)
w_plus  = clip(w_plus  + d, 0, 1.5)
w_minus = clip(w_minus - d, 0, 1.5)
```

静默输入不更新。这里 e 是解析的突触资格迹近似，并没有实现跨脉冲事件的迹动力学。
两个通道的效价和相反更新方向是人工设计，不能直接贴到实际 MBON 类型上。
reward 是外部提供的 0/1 教学信号，delta 也不是由实际 DAN 回路计算出来的。

固定 η=0.15、τ=0.5 s、160 次训练、400 次独立噪声测试；5 个预设 seed
为 11/23/47/83/131。参数用于机制检验，不来自生理拟合。
A 有奖励、B 无奖励；反转期使用独立响应噪声，改为 B 有奖励、A 无奖励。
每项对照共享初值和训练输入。测试只读取权重；学习曲线为描述性记录，未据其调参。

| 条件 | 测试 A−B 输出均值（5 seeds） | seed 最小—最大 |
| --- | ---: | ---: |
| 奖励配对 | 0.9986 | 0.9927—1.0105 |
| 冻结权重 | 0 | 0—0 |
| 关闭教学门控 | 0 | 0—0 |
| 保持奖励总量、打乱配对 | 0.0232 | −0.2262—0.2949 |
| 奖励延后 2 s | 0.1376 | 0.1359—0.1391 |
| 交换奖励对象后 | −0.9934 | −1.0073—−0.9766 |

这些是无量纲的奖励预测输出差，**不是准确率、行为偏好指数或真实果蝇测量**。
有限样本和恒定学习率使打乱奖励的单 seed 仍有残余差异，完整分布保留。
延迟效应由设定的指数衰减产生，是实现检验，不能作为发现生物时间窗的证据。
保存并重载全部 seed 权重数组逐位一致；7 项机制测试通过。

## 4. 引擎接口核查与实现路线

基线 `brian2-rust/README.md` 和 `examples/stdp_throughput.py` 已包含显式连接的
event-driven pre/post 塑性；Device 支持相应可变逐边状态。
`python/brian2_rust/device.py` 的 binary CSR 接口仍为不可变参数，
导出器拒绝 procedural 可变逐边状态，并限制此类网络单 activation 运行。

优先路线为 **静态背景图 + 独立显式 KC→MBON 可塑投影**，而非首先开放全部大图权重。
这可利用较小的 62,261 条候选边，但不能绕开以下约束：

1. 从静态投影中剔除被选可塑边；用原图 edge ID 检查两部分互斥且并集完整，避免双重传递。
2. 以 `multiplicity * gain` 表示接触数量与学习增益，gain 有界且非负；不把改增益叫改变接触数。
3. 先选择一个有依据的分区及对应输出，记录未建模的边界输入。
   在局部子图完成验证前，不把 96 个 MBON 全部加入同一个全局学习信号。
4. 对静态 CSR 多轮训练仍需正式的生命周期方案。首版可采用一次连续 run 内的训练/测试时程；
   或明确地每轮重建运行并只携带权重，接受其成本。不能删除重复 run 保护冒充支持。
5. 训练持久状态包括权重；短期活动状态包括 v/ge/gi、不应期、迹、时钟、RNG 和 pending 队列。
   定义连续试验与独立 probe 的边界；测试必须彻底关闭塑性并断开外部奖励输入。
6. 每个 checkpoint 保存原图、边划分、规则、精度、刺激和状态身份；恢复后比较完整权重与脉冲。

尚未验证此基线上的 GPU/MPI 学习能力。本研究首先建立 CPU/独立参考，
后续后端扩展需要独立能力审计，不复用 vision 分支的结果充当本分支验收。
