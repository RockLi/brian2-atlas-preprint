# 扩展性能验收：进行中

用户明确要求同时满足两项：相对改动前 Rust（`0bc46a10`）无性能回归；全规模 LK 的单线程、首次运行和峰值进程树内存均不劣于旧 C++。验收使用 Mac Studio 27 与 Linux 23，Mac Air 只提供小机器验证。

**尚未完成，不能据此宣布替换旧 backend。** `REGRESSION_20260907.md` 是此前 V2 回归报告，不代表本次扩展验收已通过。

## 已实现的冷启动候选

- 一次 AOT 构建只创建、校验一个私有模型快照，代码生成与实例写入共用该快照；公共入口继续验证协议哈希。
- 实例按块解码十六进制位模式，保持各整数宽度、浮点负零及次正规数的原始字节。
- 按块计算 canonical JSON 哈希并写入紧凑模型文件，避免完整实例 JSON 的额外临时副本。
- 均匀的 `lastupdate` 初值复用不可变字符串，保留原有 wire 数据。

新增校验覆盖分块边界、全部七种存储类型、canonical 编码、非有限数拒绝、公共模型不被修改和篡改拒绝。冷启动改动不改变生成的数值运算代码。

## 全规模 LK 首次运行诊断

模型为 4,000 E + 1,000 I、4,996,178 条连接，完整运行 11 秒。以下每格为 **一次冷启动样本**，用于定位瓶颈，不能替代最终重复测量验收。每机 Rust 版本使用相同的编译与输出路径；实际加载模块的路径、哈希均记录并核验。

| 主机 | V3 Rust 时间 / 峰值内存 | 冷启动候选 | 加紧凑 IR 写入 | C++ 1 线程 |
| --- | --- | --- | --- | --- |
| 27 | 75.57 s / 4.13 GiB | 63.59 s / 3.56 GiB | 61.04 s / 3.48 GiB | 46.80 s / 0.95 GiB |
| 23 | 87.50 s / 3.84 GiB | 77.29 s / 3.58 GiB | 73.15 s / 3.16 GiB | 51.43 s / 0.88 GiB |

候选与 V3 的 `main.rs`、`instance.bin`、`results.bin` 哈希全部一致。27 的生成阶段从 26.36 s 降至 10.70 s，编译仍约 1.77 s；校验约 3.65–3.91 s。剩余峰值出现在原生模拟开始前、有子进程存活的阶段，需要进一步区分 Python IR 与 Rust 验证器内存。

第一轮 `cold-probe` 的候选被 benchmark 内置导入路径覆盖，实际仍加载旧包，**不用于收益判断**。原始记录保留；有效数据来自 `cold-probe-v2` 与 `cold-compact`，两者均在运行前校验实际加载代码。

## 热循环诊断

23 的完整 LK 阶段剖析：Poisson 输入约 15.30 s、post 塑性约 12.89 s，是主要热点。剖析带有计时开销，不能替代正常运行基准。

已有实验均固定源码、二进制输出和运行路径；每线程配置预热一次，随机交错采样五次，并要求每次完整输出字节一致。

- 扩大 post 内联没有稳定收益，未进入正式生成策略。
- 本机 CPU 指令实验使 23 单线程 LK 热身后中位数约改善 6%，尚不足以补齐差距；未修改正式编译默认值。
- 精确缓存 post 指数计算实验约改善单线程 6%–8%，多线程收益较小；仍为实验，没有写入正式运行时。
- 后续实验检验零乘数下精确二项分布的等价快速路径，保留概率合法性检查、负零和独立计数器随机流语义；尚无验收结论。

## 后续进展：完整 LK 与验证器内存

完整 11 秒单线程交错对照完成，每种配置预热后测量 5 次，所有 Rust 结果逐字节一致：

| 主机 | Rust 控制组 | 零权重优化 | 加本机 CPU 指令 | C++ |
| --- | ---: | ---: | ---: | ---: |
| 27 | 26.879 s | 21.502 s | 21.453 s | 30.747 s |
| 23 | 40.868 s | 34.027 s | 31.871 s | 33.549 s |

零权重优化已整理成通用候选，保留非法概率拒绝、负零和高斯负尾样本行为；稠密权重表继续使用原路径。本机完整 276 项测试及 133 个子测试通过，追加 f32/f64 权重位级检查 7 项通过。本机 CPU 编译默认值未改变。指数缓存组合在 23 上仍慢于 C++，未采用。

独立紧凑验证器原型用压缩常量数组和内联位字符串减少堆分配，保留协议哈希及原有模型校验。5 次测量中，验证器自身峰值降为 27 的 112.6 MB、23 的 92.8 MB；验证时间分别为 4.249 s、4.296 s，原验证器为 3.605 s、4.526 s。本机保存的 150 个小模型交叉检查暂无接受/拒绝差异。

这些是**独立验证器指标**，不能据此宣布完整进程树内存已达标。原型尚未进入正式 Rust runner。完整冷启动组合、45 模型验证器交叉检查和全模型性能矩阵正在继续；23 STDP 的当前性能区间仍重叠，保持未决。归档任务曾与线程性能测量重叠，相关 PoissonInput 线程数据须追加复测后才能用于验收。


## 后续进展：私有数组与完整矩阵

两机 45 模型性能矩阵已完成，完整结果逐字节一致。全规模 LK 单线程相对 Git Rust 基线的几何加速比分别为 27 的 1.419、23 的 1.308；热身后单线程为 1.366、1.243。小规模 LK 和 23 STDP 有未决项，追加 33 对样本仍未全部解决；受归档干扰的 PoissonInput 线程配置正在单独复测。23 的全部 PoissonInput 复测已显示收益。
