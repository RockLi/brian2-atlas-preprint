# 科研计划更新说明

本次按讨论更新现有计划，主报告与 PDF 使用原路径。修订仅涉及计划文档与生成文件，未启动 ANN 训练、数据下载或脑区模拟。

- 执行顺序调整为：ANN 基准、局部脑区复现、三脑区耦合、统一任务和真实数据验证、关键尺度实验。
- 增加 ANN 首轮协议：危险学习、相似场景、安全更新和再次变化；区分固定权重测试与在线适应，明确记忆状态和检查点的使用。
- 明确来源区分等假设在基准后筛选；不以 ANN 失败或 SNN 胜出为预设结果。
- 补充 Hippocampome、杏仁核模型、Hass 前额叶模型和 Allen 投射图谱的用途、移植要求与缺口。
- 分开输入相似性、学习后表征重叠和行为泛化；新增时间间隔操纵用于区分感官相似与记忆关联。
- 修正执行器能力表述：已有 STDP、可变突触、分段运行与检查点基础，剩余工作是具体学习规则及 MPI 联合闭环验收。
- 调整六个月工作包，新增两个可执行附录；保留独立合作课题、公开数据、无新增患者或主动 EEG 采集的边界。

编辑与构建源：`report_content.py`、`build_report.py`。主 Markdown 可独立编辑；重新构建会由内容源覆盖生成的 Markdown，因此同步修改宜在内容源完成。
