# FLM / Flies Are All You Need：实现原理与项目启发

核查日期：2026-09-12。直接读取演示页面、论文全文 HTML，以及作者公开仓库的固定提交；没有运行 FLM、下载其大模型权重或独立重现论文成绩。

**结论：两个链接是同一项目的演示和作者预印本。其语言能力来自冻结的 LFM2.5-1.2B；MaleCNS 连接图是固定的非线性循环特征模块，末端小读出经训练后微调下一个 token 的分数。论文没有证明果蝇图带来额外语言优势，等参数的无图对照略好。**

来源：[演示](https://fly-language-model.vercel.app/)、[论文](https://artificialscientific.com/papers/flies-are-all-you-need)、[固定源码提交](https://github.com/nftechie/flm/tree/d60610ff6af1efafaa8032c5302c3b02e9dd227f)。论文发表于 2026-09-11，标为未同行评审的预印本。

## 1. 两条并行计算路径

```text
当前 token → 冻结词嵌入 → 冻结 LFM2.5 → 基础 next-token logits ──────┐
                    └→ 固定随机投影 → 固定果蝇图 → 汇总           │
                                               ↓               │
                                         可训练小读出           │
                                               ↓               │
                                       有幅度上限的 logits 修正 ─┤
                                                               ↓
                                                        相加、采样下个 token
```

生成的 token 又进入两条路径继续计算。图确实参与结果计算，但它不是承担全部语言任务的主体。骨干为 `LiquidAI/LFM2.5-1.2B-Instruct`，论文加载值 1,170,340,608 参数、隐藏维度 2048、词表 65536；词嵌入、骨干和词表投影全部冻结。公开代码用本地权重推理，没有用远程聊天 API 替代这项计算。

实现依据：[model.py](https://github.com/nftechie/flm/blob/d60610ff6af1efafaa8032c5302c3b02e9dd227f/flm/model.py)。

## 2. 解剖连接图变成了什么数学对象

数据是 **MaleCNS v1.0 雄性中枢神经系统**，不同于我们当前使用的雌性 FlyWire 全脑。按作者声明的注释/端点过滤规则，保留 166,700 节点、25,582,938 有向连接、124,177,617 接触数。“全部保留图”指该过滤规则后的全部图，不是完整生理重建。

以突触后细胞为矩阵行，突触前细胞为列：

```text
W[i,j] = contact_count[i,j] / max(1, sum_j contact_count[i,j])
```

有输入连接的行和为 1，无输入的行保持零。权重全部非负，绝对接触总量被行归一化；它是按接触数加权的输入平均，不能当作测得的突触效能。没有保留神经递质决定的兴奋/抑制符号，没有电导、形态、传播延迟或神经调制。

2048 维 token 嵌入先经固定高斯矩阵投影并归一化为 128 维 `c_t`。每个图节点随机分配一个输入通道和一个 ±1 符号，构成固定稀疏映射 B。输出端也用固定随机分桶和符号，把所有节点汇总为 128 维特征。这里的随机负号不是生物抑制细胞，也没有解剖学的“文字输入/语言输出”对应。

每个 token 更新所有节点一次：

```text
x_t = tanh(W @ (0.6*x_(t-1) + 0.4*B*c_t))
f_t = normalize(P*x_t)
```

注意旧状态与本次输入先混合，整个混合量再经过 W。t 的单位是 token，不能换算为某个生物毫秒；x 是抽象连续状态，既不是膜电位也不是脉冲数。固定循环网络将输入序列变成特征，只训练输出层，这就是储备池计算（reservoir computing）的基本做法。

实现依据：[graph.py](https://github.com/nftechie/flm/blob/d60610ff6af1efafaa8032c5302c3b02e9dd227f/flm/graph.py)、[prepare_graph.py](https://github.com/nftechie/flm/blob/d60610ff6af1efafaa8032c5302c3b02e9dd227f/scripts/prepare_graph.py)。

## 3. 真正学了什么

唯一可训练部分是两层无偏置网络，128→128→2048，GELU 中间激活：

```text
delta_t = 0.03 * tanh(V * GELU(U*f_t))
trainable_count = 128*128 + 2048*128 = 278528
```

2048 维修正经骨干的冻结词表投影变成 logits 修正，再限制其在整个词表上的 RMS 不超过 0.25，最后加回基础 logits。这个上限不是每个词分数的绝对上限，也不是输出改变概率的上限。

训练使用下一 token 交叉熵，加 0.5 倍相对基础模型的 KL 项，避免偏离骨干过多。论文拟合集为 64 个 SmolTalk 对话加 32 个合成教学对话，共 3232 个监督目标 token；AdamW 训练 3 个 epoch。连接图、图状态更新系数、随机接口、语言骨干均不学习。没有在线可塑性、多巴胺奖励或持久个人记忆；每次请求新建储备池并重放所含上下文。

注意 `FlyAdapter` 类的原型默认 scale=0.15；当前 conversation 配置实际覆盖为 0.03，不能只看默认值。实现依据：[conversation_config.py](https://github.com/nftechie/flm/blob/d60610ff6af1efafaa8032c5302c3b02e9dd227f/flm/conversation_config.py)、[train_conversation.py](https://github.com/nftechie/flm/blob/d60610ff6af1efafaa8032c5302c3b02e9dd227f/scripts/train_conversation.py)。

## 4. 论文结果真正支持什么

以下为作者报告，未由我们重跑。32 个新留出对话、1236 个目标 token、3 个拟合 seed，NLL 越低越好：

| 条件 | 平均 NLL |
| --- | ---: |
| 冻结语言骨干 | 1.381995 |
| 果蝇图 + 小读出 | 1.359816 |
| 不经过图的等参数直接输入读出 | **1.359328** |
| 节点相对接口重标号，读出不重新训练 | 1.381265 |
| 删除全部边 | 1.381995 |

果蝇分支相对骨干有小幅收益，但直接输入对照略好，三个配对拟合均如此。Fly-minus-direct 为 +0.000488 nats/token，描述性对话 bootstrap 区间 [+0.00000502,+0.00104]。这没有证明两者严格等价，更没有证明果蝇拓扑有优势。

删除边后修正严格为零是公式设计的性质：W=0、零初态、保零归一化、无偏置读出共同保证。它验证实现和分支因果影响，不能验证该拓扑比任意图好。节点重标号仍是同构图，只改变相对输入输出接口的对应；读出不重新拟合，性能下降也不能充当“随机图不如果蝇图”的证据。

真正更强的结构对照包括同预算重新训练的保度重连图、权重打乱、匹配随机储备池及多个随机接口。论文明确这些尚未完成。论文的完整确认实验划分、逐 token 损失、六套拟合读出尚未公开；开源仓库是开发训练方案，不能因此说论文确认结果已可独立完整复现。

论文还指出，在相同后续输入下，原始状态的初态差异满足上界：

```text
||x_t-z_t||_infinity <= 0.6^t * ||x_0-z_0||_infinity
```

这是非负行归一化、0.6 递归系数和 tanh 的 Lipschitz 性质决定的强收缩。10 个 token 后上界约为原来的 0.00605。该结论仅针对原始状态、同输入及精确算术；不能直接外推到归一化特征或分叉后的生成文本，也不限制语言骨干自己的上下文能力。因此节点数大不代表这个分支具有长时记忆。

## 5. 和我们的实验怎么对上

| 路线 | 图内计算 | 学习位置 | 本次证据的用途 |
| --- | --- | --- | --- |
| 当前 FlyWire LIF | 有兴奋/抑制的电导、阈值、脉冲 | 当前视觉实验主要学习外部读出 | 检验我们选定动力学和接口下的响应 |
| FlyVis | 连续活动与 ReLU 分级释放 | 类型偏置、时间常数、类型对增益，加任务读出 | 用任务标定内部动力学，再检查神经调谐 |
| FLM | 全正行归一化传播、tanh、按 token 更新 | 只学习末端 278528 参数读出 | 演示图能参与语言生成，并用对照检验是否有额外收益 |

本轮 FLM 最值得借鉴的是 **等参数直接输入对照和清楚的贡献分解**。对我们后续视觉工作，应该问：同样训练预算的小模型、绕过图的读出、随机/重连图，能否解释收益？“断开图就变差”和“真实图比替代图更好”是两个不同问题。

它没有推翻我们刚完成的 [FlyVis 参考结果](../validation/flyvis-reference-v1/README.md)。前者保留图内参数不动并加入强语言骨干，后者用视觉任务学习内部参数；输入任务、动力学、学习位置都不同。也不能用 FlyVis 的良好视觉响应证明 MaleCNS 对语言有优势。

若以后尝试记忆任务，应先检查动力学是否会按设计迅速遗忘，再比较任务中的有效记忆；不要仅根据细胞数或“循环图”名称判断记忆容量。本次只完成原理与源码核查，未新增 FLM 仿真或训练。
