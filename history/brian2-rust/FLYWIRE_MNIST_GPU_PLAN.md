## 1. 目标与结论边界

核心问题：**保持我们现有 FlyWire 连接组和 conductance-LIF 内部动力学，能否从数字诱发的神经活动中识别未见过的 0–9 手写数字？**

第一阶段采用固定内部网络、训练线性输出层的储备池方案。完整实验应分别回答：

1. 神经活动是否包含可泛化的数字类别信息？
2. 内部连接是否提供了超出输入编码本身的信息处理收益？
3. 真实连接拓扑是否优于统计匹配的随机重连拓扑？
4. CPU、GPU 及规模需要时的 MPI（CPU），在相同任务上分别有什么吞吐、延迟和内存成本？

完成研究不以得到正面结果为条件。准确率低、真实拓扑没有优势或并行/GPU 不加速，均应保留并给出有界结论。固定内部网络的结果不能表述为“果蝇内部学会数字”；这里也不验证活体果蝇视觉或真实生物学习机制。

本期必须交付：统一数据/模型协议、全图 CPU 与 GPU 分类实现、MPI（CPU）适配入口及规模触发规则、逐样本正确重置、固定网络分类、对照和评估、可复现报告、最小数字输入展示。CPU 与 GPU 均需跑通真实任务，不能以其中一个替代另一个；MPI 的全规模运行按资源门槛触发。内部突触训练和时序记忆任务作为后续独立阶段，不阻塞本期收尾。

## 3. 冻结的生物模型

以现有 **FlyWire v783 EI 全图**为正式研究对象：139,255 个生物神经元、15,091,983 条有向加权边，代表 54,492,922 个接触。保留弱边、自环和零快速作用边；不按五个接触阈值裁剪，不改用 MaleCNS 或普通随机网络。

保留 `FLYWIRE_EI.md` 的设定：

```text
dv/dt  = (-(v + 52 mV) - ge*v - gi*(v + 70 mV)) / 20 ms
dge/dt = -ge / 5 ms
dgi/dt = -gi / 5 ms
threshold = -45 mV; reset = -52 mV; refractory = 2.2 ms
Euler dt = 0.1 ms; recurrent delay = 1.8 ms
contact reference amplitude = 0.275 mV; inhibitory multiplier = 4
```

背景仍采用 512 个共享的冻结随机输入通道，保留原背景频率、幅度和神经元映射方法。输入任务替换原 DM1 刺激，不能同时无意保留 odor 驱动。第一期不调整内部权重、E/I 比例、膜时间常数或 dt 来追准确率。

同一科学模型采用以下数值/运行契约：

| 实现 | 精度与角色 | 正确性要求 |
| --- | --- | --- |
| CPU Rust AOT | f64，必选科学基线，单/多线程 | 独立小模型、Rust reference、Brian2 NumPy/C++ 对照；重放与已声明的线程确定性精确检查 |
| MPI（CPU） | f64，分布式容量路径 | 固定输入与同源码 CPU reference 对照完整状态、事件和特征，跨 rank 数保持已声明的逐字节一致性 |

数据切分、图、人工投射、背景、时序、读出细胞和正则搜索预算共用。分别拟合 CPU-f64 与 GPU-f32 的输出层并记录 backend/precision；不得把 GPU 特征直接交给 CPU 输出层而不验证。另设固定 CPU 输出层跨后端推理对照以量化迁移误差；MPI 经 f64 特征一致性通过后可复用 CPU 输出层。缓存和模型制品显式标注精度与后端。

## 4. 数据与输入协议

### 4.1 数据切分

使用原始 MNIST 28×28 灰度数字，保留官方 60,000 训练 / 10,000 测试边界。从官方训练集固定、分层抽取 50,000 fit / 10,000 validation。保存样本原始索引、文件摘要、分割 seed 和标签直方图。

所有预处理统计、输入校准和输出层拟合仅使用 fit；validation 用于选参。锁定实验协议和模型后才运行官方 test。开发阶段用 validation 子集做冒烟，不反复查看 test。未经作者身份元数据支持，不声称自行验证了按书写者独立切分。

主试验不增加旋转/扭曲增强；像素固定缩放到 [0,1]。手写画板单独执行居中和尺寸归一化，保存最终送入模型的 28×28 图片。画板数据属于域外展示，不并入 MNIST 准确率。

### 4.2 初版人工编码

优先采用可复现、无需额外视觉网络的编码：

1. 784 个像素通道，亮度决定刺激脉冲概率，暗像素不额外发放。
2. 每个通道固定投射到 4 个不同的、注释中的 ALPN 神经元；全图中当前有 685 个 ALPN。固定随机投射不训练，并记录 root ID、扇出和覆盖率。
3. 投射幅度按扇出归一化，防止换映射时总输入无意增大。外部输入通过额外 `Synapses` 增加 `ge`，不改变已有内部边。
4. ALPN 只是人工信号接入点，**不称为天然视觉通路**。后续有可靠 retinotopy/视觉细胞映射后再做独立视觉版本。

保持主输入与读出集合不重叠。通道投射、模型初始态、背景、像素脉冲、重连图和数据切分使用独立 seed；脉冲随机数由 sample ID、重复编号和 encoder seed 决定，绝不使用标签。改变处理顺序不改变单一样本输入。

首轮时间协议：100 ms 无数字背景预运行，200 ms 全图静态刺激，50 ms 撤去数字后的响应。dt 仍为 0.1 ms。读出覆盖刺激期的四个 50 ms 窗口；尾段用于诊断，初版不加入特征。

输入校准只搜索 6 个配置：最大像素脉冲率 {20, 60, 120} Hz × reference amplitude {1, 3} mV，电导换算沿用现有 `/52` 约定。它们是待验证的人工刺激参数，不是生理测量。一个 seed、固定 1,000 fit / 500 validation 用于筛选；若全部导致静默、饱和或无传播，报告并单独修订输入假设，不扩大内部模型调参范围。

## 5. 逐样本执行与特征

### 5.1 每张图片必须是独立试验

每张图片恢复相同的初始模型状态并完成上述预运行；该方式先作为慢但明确的参考路径。不能仅把 `v` 设回静息值：必须包含 ge/gi、不应期、所有输入游标、时钟、随机状态、延迟队列及统计状态。

优化路径可以缓存共同背景预运行后的完整状态，但只有在与“从头预运行”结果一致后采用；预运行结束时可能仍有 pending 事件，不能丢掉。所有后端使用同一随机输入协议。MPI 首版优先每样本从 tick 0 完整重放预运行，不能传入目前不支持的 pending/continuation 状态；其 checkpoint 优化另列，非单张分类的前置条件。

必须覆盖 A→B→A、B→A、分批大小变化、同后端同 seed 重放、空白图和失败后重试。A 的结果不得受前一张图片或批次边界影响。

### 5.2 binary CSR 生命周期是 P0 工作

按先正确后提速处理：

- 先以现有 CSR 单 activation 路径跑通少量样本，取得参考结果。
- 核对原始 wire graph 和 Rust 初始化结果后，设计受支持的“固定拓扑、多输入、独立重置”执行入口。可复用宿主初始化与编译，但每次都校验新的输入、绑定和可变初值。
- 对齐现有 executor/Device 生命周期，保留 source/target/weight/plan 身份。若需要新增 API，先定义 reset、输入更新、输出所有权、缓存失效和异常释放契约；不直接删除 procedural 重复 run 的保护。
- 编译制品复用、拓扑加载、进程启动和结果读取分别计时。仅在生成源码、模型结构和编译身份相容时复用二进制；新输入必须重新绑定和验证，不能把旧输入的 replay 当作新样本推理。
- GPU 分别记录实际编译/分配复用、上传和读回；跨输入不得无验证地复用仅针对 exact-input 的调优决策。
- MPI 新样本的全局输入身份、rank-local 分片、全局神经元/边 ID 及 RNG 身份必须一致。允许首版重复启动固定编译的程序，但将启动/分片加载成本纳入实测；不要移除续跑保护冒充常驻 batch。
- 不把每张图片重新展开 1,500 万条边或重新编译作为最终批量执行方案。

### 5.3 小型、固定输出层

主读出选取 512 个 KC（按 root ID 与固定 hash seed 无标签抽样）和全部 96 个 MBON；四个时间窗的放电计数/频率形成 **608×4=2,432 维**特征。保存被选细胞列表，不能按 test 标签挑“最会识别数字的神经元”。

fit 上求标准化参数，零方差维度显式处理。训练多类别 L2 线性分类器，预测只依赖这些活动特征；不拼接原像素。输出正则强度在固定对数网格中由 validation 选择，各对照使用相同预算。

先使用 SpikeMonitor 完整事件完成小规模特征提取和正确性基准。正式全图吞吐必须评估监控内存：放电历史、运行期投递历史、状态轨迹和结果解码分别计入，不能只计算连接权重。

若现有路径超出预算，新增通用“指定神经元、指定时间窗的脉冲计数”能力，按真实 threshold 事件、清晰定义的 [start,end) 窗口累计整数计数，仅传回特征；以完整事件离线直方图作为独立基准。该能力只替代观测，不能破坏突触投递需要的历史。窗口计数接口在各适配器中保持一致；MPI 由神经元 owner 计数并保序归并，不采用当前禁止的可变突触来模拟监控；GPU 需检查设备历史缓冲和计数溢出。不要通过加长 dt 或丢弃实际脉冲节省成本。

首版实现选择四个只用于观测的神经元状态计数器，在 reset 的脉冲事件上按整数 tick 窗口累计，不参与膜电位或突触计算。CPU/GPU/MPI 共用相同表达式；已用完整脉冲直方图和移除计数器后的动力学进行对照。这避免修改 monitor 协议，但仍保留执行后端需要的事件历史和最终状态；不能称为已经解决所有全图观测内存成本。

训练特征分片落盘并支持中断恢复，不保存所有样本的全脑电压。70,000×2,432×4 bytes 约 681 MB（十进制），但拟合、标准化和缓存副本需要额外预算；不构造样本数平方的 Gram 矩阵。只有固定演示样本保留较详细轨迹。

## 6. 实验矩阵与解释

| 编号 | 条件 | 回答的问题 |
| --- | --- | --- |
| C0 | 原像素 → 同类线性分类器 | 简单直接分类基线 |
| C1 | 固定投射后的输入统计 → 线性分类器 | 输入编码本身能做什么 |
| F | 完整真实拓扑、固定内部权重 → 主读出 | 当前 FlyWire 网络的任务表现 |
| R | 统计匹配重连图 → 同样读出 | 真实拓扑是否有额外价值 |
| Z | 内部突触传递全部禁用，保留输入与背景 | 排除输入旁路、样本状态或标签泄漏 |
| L | 打乱 fit 标签重新训练 F 的输出层 | 标签泄漏和不当评估检查 |

R 使用有向双边交换，匹配入/出度，并保留每个源的递质符号及出边权重集合；不通过改变细胞类别、读出集合或输入投射获取优势。规定自环/重边策略并验证，记录边交换比例、连通性和实际统计；重连失败不能悄悄改成普通 Erdős–Rényi 图。多个模型 seed 对应独立重连结果。

主输入为 ALPN，读出为 KC/MBON，因此 Z 下数字原则上不应影响读出；同一背景 seed 的两张不同图应给出相同读出活动。这个配对数值检查比只要求“约 10% 准确率”更强。

干预演示另做：固定输出层，比较随机关闭、按连接度关闭和按读出权重关闭部分神经元。退化表示当前模型依赖被干预单元；不能据此证明生物拓扑最优。干预不是主分类训练的替代证据。

主指标为独立 test top-1 accuracy，附 macro-F1、10×10 混淆矩阵、每类召回率、至少 3 个预设模型 seed 的结果。F/R 使用同样的样本与输入随机数，报告配对准确率差和分层重采样区间；区分固定模型的样本不确定性与 seed 间变化，不能把重复仿真同一 seed 当作独立实验。

本计划设定的展示目标是 test accuracy ≥80%，它是产品目标而非预言或科学成立门槛。若未达到，仍完成报告。F 的效果高于机会水平只支持可解码；F 超过 C1/Z 才支持额外处理贡献；真实结构优势要求 F/R 的预设比较支持正面差异。任何结构优势结论限于选定任务、动力学、输入接口和重连对照。

| --- | --- |
| CPU，必须 | 全图 0–9 特征提取、输出层训练、正式测试和单/多线程成本 |
| GPU，必须 | 维护 Metal/CUDA 适配；至少一种真实 GPU 完成与 CPU 相同冻结数据规模的训练/正式测试，另一种在可用真机上验证固定样本、精度与生命周期；未验证的平台明确标为待验收 |
| MPI（CPU），大规模条件启用 | 适配入口、能力/分区检查及小样本 1/2/4 ranks 对照；达到下述规模触发条件后做全图分布式分类、资源和结果验收 |

若 GPU 尚未通过，不将 CPU 完成写成整个多实现项目完成；若只有部分数据规模可运行，各后端使用共同规模对照并说明全量缺口。第二 GPU 平台的缺测不冒充通过，也不要求所有 seed 在所有硬件重复训练。

MPI 规模触发条件：单模型预计内存超过所选单机作业预算，或可运行的代表性试验显示分布式有容量/吞吐收益且能满足总资源预算。小规模优先单机；CPU 样本分片并发与单网络 MPI 分区是两种模式，分别报告，不混算加速比。MPI 的全量评估可以复用已通过精确一致性的 CPU 分类器，不必重复拟合同一特征矩阵。

1. **小图验证**：构建 32–256 节点的可手算 E/I 传播链、分支和延迟案例；独立 f64 参考、Brian2 NumPy/C++ 与 Rust AOT 比较完整状态、脉冲坐标、特征，遵守现有数值契约。GPU 同时通过独立/编译 f32 控制组；MPI 小样本检查 1/2/4 ranks 完整结果及空分区等边界。
2. **真实小图集成**：用现有提取工具导出注明边界的子图，保留本期背景协议，不直接套用浏览器独立背景。这里只验证管线，不能代表全脑准确率。
3. **全图复用门**：沿用已经验收的 CSR/AOT 路径，检查节点/边/权重/符号/初始状态哈希。测量主机初始化、CSR 和事件队列、临时副本、结果缓冲及完整进程树峰值；GPU 加计设备布局与传输暂存，MPI 加计每 rank、每节点及总内存。
4. **全图短跑门**：先空白、最亮图、典型数字及高活动输入；检查非有限值、电导、放电率分布、特征非退化以及与参考的差异。选择少量代表样本做完整独立对照，不能只挑分类一致的样本。
5. **持续运行门**：CPU 与主 GPU 各至少 200 个独立样本，MPI 在启用时执行同类检查；无内存持续增长、无输入串扰、无重复编译爆炸；进行异常后的释放和恢复检查。

内存预算由实际可用 RAM、GPU 显存/统一内存及 MPI 各节点预算决定，预留系统空间。分别报告 Python 前端、编译器、原生进程和并发进程总峰值，不能把历史单个原生进程 RSS 当作完整任务预算。多进程数与每进程线程数一起控制，避免超配 CPU 和内存；拟合阶段也限制 BLAS 线程争用。GPU 的单缓冲限制不是任务总内存上限，MPI 的单 rank RSS 也不是集群总内存。

计时分别报告：图导入/初始化、导出验证、编译、输入编码、进程启动、原生仿真、结果读取/特征聚合、输出层训练、单张冷启动、稳态每秒样本数和 p50/p95 延迟。至少 1 次预热、5 轮交错单线程/多线程 AOT 测量；线程候选为 1/2/4/8 中不超过主机资源额度的档位，选择端到端表现最好的已测配置。小模型无需强行使用多线程，性能对照不要求战胜其他模拟器。GPU 再分列宿主准备、编译、上传、核执行和读回，交错对照同机最佳已测 CPU 配置并标注 f32/f64；不同机器只报告各自测量。MPI 分列初始化、计算、脉冲通信、同步等待和收集，报告节点/rank 数及端到端收益，不承诺线性扩展。

在 100/1,000 样本上测量后，用 `剩余样本数×实测每样本耗时×配置数` 估计全量时间，并计入每 seed 的准备和重复成本。将初始化一次可复用的部分单列，不线性重复计费；不得从旧 ring benchmark 外推 FlyWire 吞吐。

冻结一期搜索预算：6 个输入配置；确定后不再扩展。正式 F/R 至少 3 个预设 seed；C0 确定性，C1/Z/L 按实际依赖配对。先完成全图 1,000 fit/500 validation，再扩大到 10,000 fit/2,000 validation，最后 50,000 fit/10,000 validation 与 10,000 test。小图成功不能跳过全图资源门；全量成本不可接受时交付明确标注的数据规模结果和瓶颈，不能伪称完成正式全量评估。

## 8. 分阶段交付与退出条件

| 阶段 | 开发内容 | 验收与下一步 |
| --- | --- | --- |
| P0 基线冻结 | CPU/GPU 与 MPI 分支集成身份、环境、能力探针、全图预算 | 明确各后端精度与生命周期；MPI 触发规则固定 |
| P1 可重复特征管线 | 共用模型/编码/读出，CPU、GPU 与 MPI 适配和重置 | CPU/GPU 小图参考及全图样本通过；MPI 分区对照；A→B→A 无串扰 |
| P2 首个分类结果 | CPU/GPU 同 split 的 1k→10k 特征与各自输出层；判定 MPI 全图启用 | 特征非退化、Z/L 有效，分别报告 validation 指标和全量成本 |
| P3 正式评估 | CPU 与主 GPU 的全量 F/R/C0/C1/Z/L、预设 seeds；MPI 按规模启用 | 锁定后正式 test；各实现结果/精度/性能独立报告，不能互相代替验收 |
| P4 最小展示 | 画板、实际 backend 选择、预测、活动、测试统计 | CPU/GPU 新输入均可运行；MPI 服务在启用时可选，标明预计算与现场运行 |
| P5 后续研究 | 内部可塑性或逐行输入的记忆任务 | 单独设计协议，不算一期已完成能力 |

P0/P1 的多实现集成、批量运行、生命周期和观测成本决定工作量；暂不承诺固定天数或准确率。开发按上述门槛推进，不启动与数字分类无关的新后端全面优化。

若 F≈R：完成负结果，不无限调参寻找生物拓扑优势。若 F≈C1：报告额外网络处理收益不足。若 F/Z 都很高：先排查旁路、样本 ID 和跨样本状态，不发布正面结果。若多线程、多进程、GPU 或 MPI 更慢：保留必需实现及负结果，默认使用最佳已测配置；只优化有证据的准备、图加载、进程启动、通信或记录瓶颈。

## 10. 后续内部学习阶段的范围

只有一期完成后，才增加“固定拓扑但允许部分内部权重变化”的实验。CPU AOT 与 GPU 已支持部分 STDP 不代表现成监督训练算法；MPI 当前尚不支持可变突触，需要另行扩展和验收。需要先选择学习规则、可变边集合、权重约束和训练/测试时的学习开关。

建议从有界的小回路或指定投影开始，保留细胞符号和边身份；与同图冻结条件、统计匹配随机图、相同训练预算对比。测试期间关闭塑性，不能让测试样本持续训练模型。自动微分/BPTT、替代梯度、奖励调制学习属于不同实现路线，不能混用术语或在首版承诺全脑端到端训练。

逐行 MNIST 可另检验时间记忆，但必须增加“相同分窗输入直接分类”和“清空中间状态”的对照；多时间窗特征本身就保存输入顺序，不能将它的分类成功直接归因于循环网络记忆。
