# MPI integration into the Rust mainline

Target: `gate0/minimal-rust-backend` at `6530b004b`.
Source: `codex/mpi-cpu` at `35b6a6e04`.

The merge preserves the mainline GPU/WASM entry points and adds MPI planning,
rank-local execution, procedural topology, resource guards and MAM evidence.
The reference runner stays split between `main.rs`, `lib.rs` and `model.rs`;
MPI resource validation is integrated into that existing library structure.

The six overlapping source files were resolved by preserving both backends'
contracts. In particular, native dynamic spike-input overrides remain a CPU
facility, while MPI reads only its compiled, identity-bound rank shards.
GPU options, autotuning, buffer transfer and owner-clock handling remain in place.

The user explicitly authorized preserving mainline default capacities:
100,000,000 initial values, 2 GiB IR input and 10,000,000 steps per population.
Python and Rust both honor lower explicit environment limits. These preparation
limits do not reserve resources or change any admitted remote cgroup budget.

Validation runs and temporary build files are under
`/atlas-storage/0002/brian2-mpi-20260908/merge-validation-20260912`.
The initial test-collection failures are retained. A real MPI compile failure
caused by a CPU-only `SpikeInput` dependency was fixed before the final rerun.

Final clean-merge validation:

- `cargo test --offline --lib -j 2`: 6 passed.
- MPI, MPI GPU contracts, compact/prebuilt topology, explicit limits, execution
  plans, native AOT, cross-backend regressions and WASM planning: 142 passed,
  21 subtests passed, 14 opt-in tests skipped (`runtime-v3.xml`, 504.41 s).
- Explicit local MPI+Metal, GPU entry points and CPU frozen spike-input parity:
  11 passed, 2 CUDA tests skipped (`gpu-v3.xml`, 45.42 s).

These suites overlap on three CPU regression tests; their pass counts are not
independent scientific samples. CUDA execution and browser WASM execution were
not tested on this machine in this merge.

The live 1751 experiment continues from its frozen source and executable in the
original MPI worktree and on the remote hosts. This merge does not restart it,
replace its pinned artifacts, or establish scientific equivalence or a speed/cost
advantage. Historical unfavorable results remain part of the merged evidence.

The main worktree's existing uncommitted work is kept separate from this merge.
Its original patch and hashes were saved on T7 before integration; the only
overlap requiring manual restoration is `native.py` (imports and the verified
source-generation wrapper).
