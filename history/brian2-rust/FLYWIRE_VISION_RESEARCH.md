## 当前结论

**P13d 简化模型竞争解释完成：新增完整图运行0次，复用48组条件、五个固定窗口，240条指标独立复算通过。** 只保留两条直接输入强度和相同时间滤波的M0，早期符号与完整网络一致46/48，波形误差中位数28.44%；单细胞导电LIF加固定空白背景的M1为47/48和16.57%，但P13c子组误差21.55%仍未达20%标准，个别误差很大。M1重现了T4b/787的反号及AB/BA发放差异，约2.29%波形误差。简化模型内配平强度使差异归零、交换强度使其反号；M0长窗口积分近乎相消，完整网络晚期轨迹仍解释不足。结果支持输入强弱、有限窗口和局部动力学作为竞争解释，不能把早期顺序符号直接归于复杂方向回路。强度操作尚未在完整图实施。见 [P13d报告](validation/flywire-vision-minimal-response-v1/README.md) 与 [判读和下一项因果检验](validation/flywire-vision-minimal-response-v1/DECISION.md)。

**P13c 响应分解与起始时刻诊断完成：116/128 次新全图运行，独立复算及恢复通过。** 单独输入先于双输入运行形成固定预测；统一后移50ms后，16/16组原始AB−BA符号预测正确，波形相对RMS误差中位数5.64%（同组旧窗口5.27%），原始符号保持15/16，三项预定诊断标准通过。J符号仅保持9/16，新窗口所有目标条件均零发放；最大波形误差34.28%，不能把符号正确等同于幅度准确。这支持单独输入的时间叠加作为局部竞争解释，修正“J不稳即可否定原始响应”的判断；仍未证明四方向识别或FlyWire特异拓扑贡献。下一步若继续，先检验简化模型、输入不对称及有限观察窗口的解释，暂缓拓扑和视频扩展。见 [P13c报告](validation/flywire-vision-onset-diagnostic-v1/README.md) 与 [判读](validation/flywire-vision-onset-diagnostic-v1/DECISION.md)。

## 方向准确率改进（P7）

开发阶段重放原对比度输入和因果帧差输入，各 193 次原生仿真，保留 10 ms 下游计数与完整尾段。原输入重放与 P6 的全部事件哈希和原 50 ms 计数完全一致。探索了分路、噪声加权、更细时间窗、方向运动能量、特征反向增广及其组合；正式搜索含 576 个配置，每项四个正则参数。仅用原 128 条 fit / 64 条 validation，P6 旧测试不进入选择。

最终选中因果帧差 ON/OFF、T4/T5 两路、100–500 ms 的 10 ms 计数、正负残差分离与 24 维方向运动能量，外接 alpha=10 的线性 ridge，并在 fit 特征上作反向增广。开发验证 68.75%。频谱滤波针对固定训练速度，它仍是明确的外部非线性运动计算。更细记录不是单独的充分改进：原输入的局部时空相关仍由 50 ms 版本最好。

目标切断保留外部视觉驱动，只关闭 1,535 个 Mi1/Tm1 的输出传递。其全部 128 条测试下游原始计数均与切断空白完全相同。补充两个方向复跑，所有 137,720 个非输入细胞的完整事件与终态都与空白逐字节一致；恢复完整模型、重置复跑也精确重现原结果。随机对照仅一份掩码，数量、正输出、连接度和输出强度近似匹配，不含输入或读出细胞，未匹配位置、类型或活动。这证明人工输入路线的必要性，不等于定位具体 T4/T5 内部计算通路。

45.31% 的整体组区间为 32.81–58.59%；亮点 62.50%、暗点 28.13%。右/左/上/下分别 17/32、14/32、15/32、12/32。外部运动层是对真实下游脉冲投影后的非线性时空相关，再接线性读出；原始线性读出仍未超过机会水平，同算法的输入脉冲基线更高。因此不能宣称真实 FlyWire 拓扑产生识别收益。后续应在新开发组处理暗刺激与多时间尺度，再以更多独立测试组、多个随机掩码和特定内部边切断检验；不能继续用本批测试结果调参。

## 实现审查与新条件评估

## 准确率改进：输入强度与下游读出分开比较

本轮沿用原开发轨迹，排除上一轮已揭盲的留出行。先比较 16/32/64 mV 的人工对比度输入，以及 32 mV 的因果帧差输入；内部图、递质规则、背景和神经元动力学不变。模型逐字段复核确认只有外部视觉突触幅度和相应协议哈希变化。

读出比较原始单细胞计数、根据固定连接推导的 12×12 空间汇总，以及只在 fit 中筛选 128 个有方向响应的细胞。空间坐标取已审核 Mi1→T4、Tm1→T5 正连接的接触数加权中心；6,063 个细胞可映射。该投影是外部读出的工程结构，不是新取得的生理感受野。所有方案仍可写为原始下游脉冲计数的线性映射，推理不读取像素、输入脉冲或刺激标签。

筛选阶段为 64 条 fit / 32 条 validation。原输入最高 62.5%，两倍输入 87.5%，四倍输入 78.13%，因果帧差输入 84.38%。增益不是越大越好。本轮按预先声明规则选中两倍对比度输入，随后扩大到完整 128/64 开发数据选择最终读出。开发阶段另试的核读出未超过线性方案，因此未采用。

最终读出锁定后，新执行 32 组 / 128 条未用过的轨迹，旧模型与新输入模型都运行同一批片段。比较包括旧模型原读出、旧输入下只改读出、新输入配合新读出，并保留实际输入/输入细胞、时间汇总、亚型汇总和标签打乱对照。新留出成绩不能直接和上一轮不同轨迹集上的 59.4% 作配对比较。

P3 已完成 640 次新全图仿真。在同一批 128 条留出片段上，原方案为 **58.59%（75/128）**，只改读出为 **71.09%（91/128）**，两倍输入加 128 细胞读出为 **80.47%（103/128）**。后者的组重采样 95% 区间为 72.66%–87.50%，亮刺激 89.06%、暗刺激 71.88%。全部预测独立重算通过；新输入模型的 18 次可视化仿真重新通过 A→B→A 与切断/空白检查。证据见 [`validation/flywire-vision-improvement-v2`](validation/flywire-vision-improvement-v2)。

## 科学边界和输入决策

首轮候选接口为 Mi1/Tm1 的空间映射人工驱动，跳过感光细胞和部分早期处理。
这样可以先检验下游通路和现有执行器；即使成功，也不能称为从视网膜开始的自然视觉模型。
真实图中的所有细胞及已有边保留，候选筛选只限制外部输入。

下一阶段分别检查 Mi1/Tm1 的基线活动、极性响应和输入增益：先做单点闪光及亮暗阶跃，再做移动刺激。
不能仅因为名称属于 ON/OFF 通路就假定本模型已具有对应生理特性。
如果固定 conductance-LIF 无法产生合理传播，记录失败并另立早期连续电位模型实验；不靠改 E/I、阈值或加入方向标签修正结果。

空间投影采用明确的理想六角平面：`x = sqrt(3)/2*(q-p)`，`y = -(p+q)/2`。
在右眼约定中 x 正向为 posterior，图像 y 正向为 ventral。屏幕与六角坐标使用固定中心 (19,17)、尺度 22，不能解释为已校准视角或物理视网膜投影。

## P1：模型接口与小样本传播

- 从有哈希校验的完整 EI CSR 按 uint64 root ID 建立索引映射，核对节点、边、递质和模型身份。P1 已加载并验证全图 CSR；节点顺序使用真实 ID 绑定。
- 去掉原 DM1/ALPN 任务刺激，以候选细胞接入视频。亮度/ON/OFF 输入到脉冲或电流的转换需单独冻结；只用低级时空信号，不注入方向或接近标签。
- 保留原全图固定动力学作为工程基线；另记录视觉模型的科学假设和数值契约。
- 以整段视频为独立试验，片段间完整重置；片段内的帧间保留膜状态、电导、不应期、时间和延迟队列。
- 预定刺激前 100 ms、视频 400 ms、尾段 100 ms；dt 0.1 ms。采用冻结背景，多种刺激共享背景随机数。
- 初步运动读出候选为 T4/T5 各亚型；接近读出考察 LC4 及经连接核查的下游集合。均先校验来源、数量及可达路径，不能预先赋予功能或直接刺激读出细胞。
- 先 CPU f64 数值参考，再实际 Metal f32 小样本与独立 CPU f32 对照。CUDA 单列真机验收；不承诺不同精度逐脉冲相同。
- 验证完整 A→B→A 重置、空白、输入顺序、帧边界、跨帧延迟投递，以及观测计数与完整事件的一致性。

## P2：四方向识别和接近检测

两项任务分别评估，不将八种诊断刺激混成一个分类指标。

- 方向任务：四类等频，以速度、位置、大小、极性、对比度为 nuisance 参数；这些参数在标签间配平。
- 接近任务：扩大与缩小配对，加入平移和亮度闪烁负例；线性扩大只是二维视觉代理，后续加入有明确几何和 time-to-contact 的刺激。
- 配对片段、同一轨迹衍生的旋转/反转/噪声版本必须留在同一 split。fit、validation、test 由轨迹组 ID 分配；另留整档速度和对比度做分布外测试。
- 先固定小规模 256 个 fit 轨迹组、64 个 validation 组，各组生成配平类别。正式 test 在协议锁定后生成；P0 不包含 test。
- 仅用 fit 校准输入和标准化，validation 选线性读出正则。网络内部权重保持固定。
- 记录 accuracy、macro-F1、混淆矩阵、跨条件性能和响应潜伏期；接近任务另看灵敏度、误报率及检测提前量。
- 无准确率下限作为科学成立条件。必须报告失败、静默、饱和和无优势的结果。

## 必需对照

| 对照 | 用途 |
| --- | --- |
| 实际编码输入的同窗特征 + 相同线性读出 | 检验神经处理是否有额外贡献 |
| 原始视频、首/末帧、时间平均图 + 匹配读出 | 暴露静态/时间顺序捷径，避免把前端信息当作循环计算收益 |
| 真实图 F 与统计匹配重连图 R | 检验选定任务下真实拓扑的贡献 |
| 目标输入细胞输出切断，刺激/空白配对 | 验证信息是否依赖该输入通路传递 |
| 保持输入，切断指定内部通路及匹配随机切断 | 比较指定通路依赖，不将一般活动降低解释为功能特异性 |
| 帧乱序、时间反转、fit 标签打乱 | 检查时间依赖、方向一致性和标签泄漏 |

R 应以有向双边交换保留节点入/出度、每源递质符号与出边权重集合；输入和读出不变。
另考虑空间/细胞类型约束的重连敏感性对照，明确约束，报告实际交换率、距离分布和连通性。
全图随机重连会同时破坏视网膜拓扑，单一 F/R 差异不能定位收益究竟来自哪一级结构。
主比较至少三个预定 seed；配对区间按独立轨迹组重采样。

输入通路切断的刺激条件和空白条件必须一起跑，避免混入基线改变。
若所有外部任务信号仅从被切断细胞进入且读出不重叠，二者下游活动应相同；这项检查比分类恰好达到机会水平更强。

## 工程范围与下一步

本轮新增独立实验包、源锁、全图仿真、外部读出、可视化、测试和研究记录，不修改 GPU 核心生成器。
下一轮优先检查输入极性、增益及稀疏/静默响应原因，特别是 LC4；预先冻结备选编码和动力学实验，再扩大轨迹组与读出对照。37.5% 对 100% 暂不支持当前神经处理的价值，不应只增大读出器追分。之后补全统计匹配重连、内部通路/随机切断、帧乱序及标签打乱检查，最后才运行锁定 test。GPU 侧需解决事件历史的驻留内存后重跑完整 600 ms 数值检查。
片段批处理复用编译及拓扑，但必须重置全部动态状态，不能逐帧重置，也不能每个片段重新编译图。
性能记录冷启动、宿主准备、上传、仿真、读回和读出；用实际视觉任务测量，不外推 MNIST 或 ring benchmark。
遮挡记忆、闭环行为和内部学习留在后续阶段，不混入本轮识别结论。
