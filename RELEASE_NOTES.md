# Evidence archive for bioRxiv v1

Frozen manuscript sources, English/Chinese reading-page sources, figure
generators, experimental drivers, source manifests and retained measurement
records for the first Brian2 Atlas preprint version.

Paired software: [Brian2 Atlas v0.1.0](https://github.com/RockLi/brian2-atlas/tree/v0.1.0).
See `release-pair.json` for the exact software commit and release identifiers.

The manuscript rebuild verifies retained evidence and numerical consistency.
Historical measurements retain their measured source identities and scope;
archiving this version does not relabel them as newly measured results.
The [coverage audit](experiments/COVERAGE.md) describes retained experiment code
and input/build limitations. Large external arrays and some original outputs
remain separately archived, as stated in the manuscript.

Original code: Apache-2.0. Original manuscript, data and figures: CC BY 4.0.
Imported Brian2 and third-party material retain their original terms; see
[license scope](LICENSE_SCOPE.md).

`biorxiv-v1` is an immutable annotated tag. `main` holds the frozen archive;
ongoing work belongs on `dev`. The tag name does not assert a bioRxiv submission
or an assigned DOI. Reading PDFs are delivered separately, not Git-tracked assets.
